# Perfiles

Perfiles previstos para futuras entregas:

- **GE Minimal:** Openbox, Rofi y paleta base.
- **GE Gaming:** panel, accesos rápidos y utilidades de juego.
- **GE Neon:** variante visual cian/violeta.

En 1.1.0 los componentes se instalan de forma modular desde `configs/`, `themes/` y `scripts/`.
