# Versiones

## 1.1.0

- Se conserva la configuración Openbox personalizada de Archcraft GE.
- Se incluye la variante básica y la variante con `Super + .`.
- Se agrega tema Rofi Deep Space y variante Ember.
- Se agregan perfiles opcionales para Picom, Dunst, Polybar, Alacritty y Kitty.
- Se incorpora el perfil `rofimoji.rc` y el instalador gráfico modular YAD.
- Se incluyen scripts para lanzar Rofi, Rofimoji, Polybar y diagnosticar dependencias.
- Se añade instalador con respaldos y restaurador para la última instalación.
- Se amplía la documentación de instalación, atajos y solución de problemas.
