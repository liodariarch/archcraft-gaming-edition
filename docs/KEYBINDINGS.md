# Atajos principales de Archcraft GE

Los siguientes atajos corresponden al `rc.xml` incluido. `Super` es la tecla Windows.

| Atajo | Acción |
|---|---|
| `Super + Space` | Menú raíz de Openbox |
| `Alt + Space` | Menú de ventana |
| `Super + Enter` | Abrir Alacritty |
| `Super + Shift + Enter` | Abrir Kitty |
| `Super + F` | Abrir Thunar |
| `Super + W` | Abrir Firefox |
| `Super + E` | Abrir Geany |
| `Super + R` | Abrir lanzador Rofi existente |
| `Super + .` | Abrir Rofimoji |
| `Super + Shift + S` | Captura de región con Flameshot |
| `Super + 1` a `Super + 5` | Cambiar escritorio |
| `Ctrl + Alt + Left/Right` | Escritorio anterior/siguiente |
| `Super + Left/Right` | Ajustar ventana a mitad izquierda/derecha |
| `Super + Up` | Maximizar ventana |
| `Super + Down` | Restaurar y centrar ventana |
| `Ctrl + Shift + R` | Recargar Openbox |

Los atajos que llaman aplicaciones externas requieren que esas aplicaciones ya estén instaladas. Si un atajo no responde, comprueba que la tecla no esté capturada por otra herramienta o que no exista otro atajo duplicado.
